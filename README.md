# Playroom

A cheerful, responsive mini-game arcade built with plain HTML, CSS, and JavaScript. Open `index.html` in a browser to play — no build step or dependencies required.

## Games
- Snack Snake
- 2048 Mix-Up
- Match-a-Moji memory game
- Ready, Set, Tap! reaction test
- Tic-Tac-Toe against the computer
- Comet Clicker

Search and category filters make it easy to find a game. Everything runs locally in the browser; the games do not embed third-party sites or require downloads.
